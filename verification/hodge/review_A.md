# Hodge conjecture statement audit, area A: underlying space and sheaf cohomology

Repo: `external/hodge` (Paul-Lez/HodgeConjecture), Lean v4.33.1. Read-only audit. Paths below are
relative to `external/hodge/`. `Basic.lean` = `HodgeConjecture/Definitions/AlgebraicGeometry/ComplexPoint/Basic.lean`,

## Verdict

No BUG found in area A. `X(ℂ)` carries the classical analytic topology, not the Zariski topology.
`H^n(X; K)` is Mathlib's sheaf cohomology `Ext^n(ℤ_X, K_X)` of the constant sheaf on that space.
The Zariski trap does not apply. The concerns below are low severity or "not proved in the repo"
items, not misformalizations.

Kernel checks were run with `lake env lean` on scratch files in the session scratchpad
(`.../scratchpad/auditA/T1.lean`, `T2.lean`). Results are under "Machine checks".

## Concerns ranked by severity

All are LOW. None of them makes the statement trivial or false-by-construction.

1. **(LOW, not proved in the repo) `H^n(X;ℚ) → H^n(X;ℂ)` is not shown injective.** `hodgeClasses` is a
   `comap` along `fieldToDeRhamCohomologyLinear`. If the map had a kernel, every kernel element would
   count as a Hodge class. Mathematically `ℚ_X → ℂ_X` gives `H^n(X;ℚ) ⊗ ℂ ≅ H^n(X;ℂ)`, so the map is
   injective. The formal statement is correct as written. Only the claim that the construction is not
   degenerate is unproved.
   Sanity lemma: `Function.Injective (fieldToDeRhamCohomologyLinear ℚ X n)`, or first the injectivity
   of `Sheaf.H.map (fieldToComplexConstantSheaf ℚ X) n`.

2. **(LOW) No global comparison with singular cohomology.** The repo proves
   `H^n(X;ℚ) ≃+ ℍ^n(sheafified singular cochains)` (`rationalCohomologySingularCochainAddEquiv`,
   Lemmas/AlgebraicGeometry/Cohomology/SingularSheafComparison.lean:81). It also proves that the
   cochain sheaves are flasque on hereditarily paracompact T2 spaces. There is no end-to-end
   `H^n(X;ℚ) ≃ H^n_sing(X(ℂ);ℚ)`. So the non-triviality of `H^n` is argued, not shown on an example.
   Sanity lemma that would refute a hidden degeneracy: for `X = ℙ^1_ℂ`,
   `¬ Subsingleton (H^2(X; ℚ))`. An easier version: `Nontrivial (H^2(X; ℚ))` for any positive-dimensional
   projective `X`. An intermediate version: `H^n(X;ℚ) ≃+ (global singular cochain complex).homology n`
   for paracompact T2 `X(ℂ)`.

3. **(LOW) Duplicated local topology instance.** `FundamentalClass.lean:36`
   (`local instance cycleComponentSheafClassAnalyticTopology := Point.analyticTopology`) gives a second
   instance path. It is `rfl`-equal to the global one, and the statement's `≤` type-checks, so the two
   `H^(2p)(X;ℚ)` types unify.
   Sanity lemma: `example : (cycleComponentSheafClassAnalyticTopology X) = Point.analyticTopology := rfl`
   (it is `private`-free and should hold by `rfl`).

4. **(INFO) Junk branch in `evaluate`.** `evaluate U s z = 0` when `z ∉ U` (Basic.lean:136). It is never
   observable, because every subbasic set is `overOpen U ∩ evaluate U s ⁻¹' V`.
   Sanity lemma (already present): `analyticTopology_eq_generateFrom`, plus `evaluationHom_apply`.

5. **(INFO) Universe and instance choices.** `HasExt.{1}` (`analyticHasExt`) and local
   `HasDerivedCategory.standard`. Both are propositional, or are used only to transport structure.
   The `Ext`/`SmallShiftedHom` types are canonical. There is no semantic effect.
